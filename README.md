# JSA SmartRisk — Python Demo v0.1

نمونه نمایشی اولیه سامانه تحلیل ایمنی شغل (JSA) و ارزیابی ریسک برای کارشناسان و مهندسان HSE.
تمام داده‌های اولیه ساختگی هستند و هیچ الزام داخلی پالایشگاه در آن فرض نشده است.

## نیازمندی‌ها
- Python 3.10 یا جدیدتر
- pip

## نصب و اجرا

### Windows
```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

### Linux / macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

پس از اجرا، آدرس محلی نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## امکانات نسخه اول
- رابط فارسی با انتخاب زبان نمایشی فارسی/انگلیسی
- داشبورد شاخص‌های پایه
- ثبت گام‌های JSA، مخاطرات، پیامدها و کنترل‌های پیشنهادی
- محاسبه قطعی امتیاز ریسک به‌صورت احتمال × شدت
- نمایش ماتریس ۵×۵ و باندهای ریسک نمونه
- گردش کار نمایشی با وضعیت‌های پیش‌نویس و بررسی
- خروجی CSV

## هشدارهای مهم
- ماتریس ۵×۵ و باندهای ریسک صرفاً نمونه‌اند و نباید به‌عنوان معیار مصوب پالایشگاه تلقی شوند.
- وضعیت «تأییدشده (نمونه)» هیچ اعتبار رسمی ندارد.
- داده‌ها در حافظه نشست هستند و با پایان نشست ممکن است از بین بروند.
- هیچ اتصال هوش مصنوعی، پایگاه داده، احراز هویت یا کنترل دسترسی تولیدی در این نسخه فعال نیست.
- از اطلاعات واقعی، محرمانه یا حساس عملیاتی در این نسخه استفاده نکنید.

## گام‌های پیشنهادی نسخه بعدی
1. دریافت و تأیید ماتریس ریسک و فرم‌های رسمی از مالک فرایند.
2. طراحی نقش‌ها و مجوزهای HSE، عملیات، نگهداری و تأییدکنندگان.
3. افزودن PostgreSQL، احراز هویت و گزارش حسابرسی.
4. تولید PDF با نشان‌گذاری روشن وضعیت سند و نسخه.
5. در صورت مجوز سازمانی، افزودن پیشنهادهای AI با بازبینی اجباری متخصص و سیاست مشخص برای داده‌ها.
